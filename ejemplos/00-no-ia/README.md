# Ejemplo: 00 — Sistema fuera del ámbito del AI Act (No IA)

## Tipo de resultado
Fuera de alcance — No IA

## Sector
Metalmecánica

## Sistema evaluado
Hoja Excel avanzada con macros y reglas deterministas para planificar pedidos de acero, gestionar alertas de stock y generar órdenes internas de compra en una PYME metalmecánica. El sistema sigue reglas fijas escritas a mano y no incorpora ningún componente de inferencia o aprendizaje automático.

## Resultado esperado
El sistema no cumple la definición de sistema de IA del Art. 3.1 del Reglamento (UE) 2024/1689. El Reglamento no es aplicable. No se asigna rol de entidad.

## Archivos incluidos

- `conversacion_original.txt` — Conversación completa exportada del asistente AIComply
- `conversacion_evaluacion_clasificacion.md` — Conversación de evaluación y clasificación (archivo completo; no existe fase de cumplimiento)
- `conversacion_cumplimiento.md` — Nota de inaplicabilidad (sin análisis de cumplimiento)

## Uso del ejemplo
Este ejemplo ilustra el primer punto de decisión del árbol de evaluación del AI Act: la comprobación de si el sistema analizado cumple la definición de sistema de IA del Art. 3.1. Es útil para demostrar que AIComply no clasifica todo sistema informático como IA, y que el flujo puede terminar en la fase de evaluación sin iniciar análisis de cumplimiento. Resulta especialmente representativo para PYMES que usan herramientas digitales básicas y quieren saber si el AI Act les afecta.
