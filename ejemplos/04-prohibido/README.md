# Ejemplo: 04 — Prohibido

## Tipo de resultado
Prohibido (Art. 5 AI Act)

## Sector
Agroindustria (cultivo y envasado de fruta)

## Sistema evaluado
Sistema de vigilancia biométrica emocional y scoring laboral en una cooperativa agroindustrial. El sistema combina cámaras, micrófonos y pulseras biométricas para inferir emociones, estrés, cansancio, actitud y predisposición al conflicto de cada trabajador durante la jornada laboral. A partir de esas inferencias genera un score individual de fiabilidad y compromiso que se usa para asignar turnos, retirar bonus, priorizar renovaciones de contrato y seleccionar trabajadores para despido.

## Resultado esperado
Clasificación: Prohibido (tres prohibiciones acumulativas: Art. 5.1.c, Art. 5.1.f, Art. 5.1.g) | Rol: Implementador

- `informe_cumplimiento.pdf` — Informe de cumplimiento en PDF

- `informe_completo.pdf` — Informe completo en PDF

## Uso del ejemplo
Este ejemplo ilustra el escenario más grave contemplado por el AI Act: un sistema que activa tres prohibiciones independientes del Art. 5, todas en vigor desde febrero de 2025. Es útil para demostrar la capacidad de AIComply para identificar prácticas prohibidas y para mostrar que el análisis de cumplimiento en estos casos se centra en las medidas de cese, remediación y consulta especializada (RGPD, derecho laboral). Aunque el sistema está prohibido, el ejemplo incluye el análisis de cumplimiento completo, lo que ilustra el flujo de actuación recomendado tras la detección de una práctica prohibida.
